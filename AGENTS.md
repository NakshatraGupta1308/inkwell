# Project conventions

- Never mention the AI coding assistant or company used to work on this project, by name or otherwise, in git commits, pull request titles/descriptions, comments, issues, code comments, or any other content pushed to this repository or its GitHub. No co-author lines, no session links, no generated-by footers.
- Never use em dashes anywhere in this project: not in code, comments, commit messages, the README, docs, or the marketing website copy. Use a comma, parentheses, or a period instead.
